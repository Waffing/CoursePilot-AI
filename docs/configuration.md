# 大模型版使用说明

当前版本：`0.2.8.2`。原始 `0.2.8` 副本保存在 `upstream/`。

## 安装与配置

1. 在油猴等脚本管理器中导入 [greasyfork-488083.model.user.js](../scripts/coursepilot-ai.user.js)。脚本名称以“【大模型版】”结尾。
2. 停用原版以及其他同类脚本，避免同时操作同一页面。
3. 打开课程页面，在“答题 → 模型设置 → 连接”选择服务商，填写接口地址和 API Key。
4. 默认开启“自动获取模型”，停止输入约 0.8 秒后获取列表；也可点击“获取模型”。选择模型，或输入模型 ID 后按 Enter 确认。
5. 点击“测试连接”，成功后刷新课程页面，沿用原来的答题与章节流程。配置自动保存。
6. 脚本管理器询问连接权限时，允许所配模型和搜索服务的域名。

只有一个模型时自动选中；多个模型时由用户选择。远程服务自动获取需填写 Key；无鉴权接口可手动获取，本机接口可直接自动获取。服务未提供模型列表接口时仍可手动输入模型 ID。“测试连接”只发送示例算术题，不填写或提交课程题目；开启联网后测试也会调用搜索，可能计费。

| 字段 | 填写内容 |
| --- | --- |
| 接口 | 服务商提供的基础地址，例如 `https://你的服务域名/v1`，也可填所选协议的完整答题地址 |
| 模型 | 该服务商实际提供的模型 ID，必须与服务商给出的名称一致 |
| API Key | 模型服务的 API Key，不是原题库卡密；无鉴权的本机服务可留空 |

地址填写规则：只有域名时默认 `/v1`，Gemini 默认 `/v1beta`；已有路径时在其后追加所选协议的请求路径，完整地址不会重复追加。远程服务必须使用 HTTPS。本机 `localhost`、`127.0.0.1` 和 `::1` 可使用 HTTP。地址不能携带账号、查询参数或片段，Key 应填在独立输入框。

支持四种协议：OpenAI Chat、OpenAI Responses、Anthropic Messages 和 Gemini generateContent。内置 OpenAI、DeepSeek、百炼、硅基流动、Moonshot/Kimi、Claude、Gemini、Ollama 和自定义预设。中转服务须按其文档选择实际协议和地址。预设不代表每个模型、地区和网关均兼容。

切换服务商时分别恢复该服务商的地址、Key、模型和答题参数。模型列表支持 OpenAI 兼容格式、Claude 和 Gemini 分页；Gemini 会过滤不支持 generateContent 的模型。

## 联网搜索

“联网搜索”默认关闭，支持以下两种方式：

| 方式 | 配置与适用范围 |
| --- | --- |
| 服务商原生搜索 | 使用模型服务的 Key。已接入 OpenAI Responses 的 `web_search`、Claude 的 `web_search_20250305`、Gemini 的 `google_search`、百炼 Chat 的 `enable_search`。具体模型和网关仍须支持对应工具。 |
| Tavily 先检索再作答 | 使用独立的搜索 Key，默认地址 `https://api.tavily.com`。可设 1–10 条结果、基础或深入搜索；先检索，再把资料交给所选模型求解。适用于没有原生搜索的模型接口。 |

Tavily 失败或没有有效资料时停止本题，不会静默切回无搜索作答。模型 Key 与搜索 Key 分开保存、分开发送。普通 Chat 协议没有统一搜索字段，DeepSeek、Kimi、硅基流动和自定义 Chat 接口可选 Tavily。

答案下方展示实际返回的来源链接。原生模式取得搜索记录时显示“已联网检索”，未取得记录时显示“服务商未返回搜索记录”，后者不能证明执行了搜索。百炼兼容 Chat 通常不返回来源，可能出现后一种状态。Gemini 返回的 Google 搜索建议在隔离框架内展示。联网会增加耗时，也可能另行收费。

## 答题参数

| 设置 | 行为 |
| --- | --- |
| 超时 | 模型请求 10–300 秒，默认 120 秒；模型列表和 Tavily 搜索单次请求为 30 秒。 |
| 输出上限 | 0 表示不显式指定；Claude 因协议要求默认发送 2048。过小可能截断答案 JSON。 |
| 自定义温度 | 默认不发送；开启后通常为 0–2，Claude 限制为 0–1。部分模型不接受温度参数。 |
| 答题偏好 | 可补充语言、措辞和资料偏好，脚本保留题型和 JSON 输出约定。 |
| 恢复答题参数 | 恢复以上参数默认值。 |

## 修改范围

- 答案来源改成用户配置的模型服务，题干、选项和题型发送给模型。
- 模型输出转换为原版 `success/data.items[].answer.values` 结构，再交给现有填写逻辑。
- 选择题的序号、字母或完全匹配文本转换为原页面选项；判断题转换为“正确/错误”；填空题保持答案数组顺序。
- 支持多协议、模型列表、搜索及答题参数，保留原来的答题间隔、取消和过期响应检查。
- 模型 Key、搜索 Key 和服务商连接配置写入脚本管理器 GM 存储，页面 localStorage 配置会去掉 Key。
- 模型答案在列表中按文本显示，避免把生成内容当作 HTML。
- 删除原 GreasyFork 更新地址，防止修改版按原地址被覆盖。用户脚本管理器是否另有更新来源，仍以其设置为准。
- 为允许自定义模型地址，声明 `@connect *`；原来的公告请求保留。

原件 [greasyfork-488083.original.user.js](../upstream/greasyfork-488083.original.user.js) 保持不变。

## 保留的原版行为与限制

按照本次要求，视频播放、章节任务、页面 hook、题目填写、考试切换、保存与提交流程保持原有实现；没有顺便修复此前报告的其他逻辑问题。

章节作业仍默认开启自动提交，阈值仍为 85。原版所谓“正确率”实际上按取得答案的题目数计算，没有校验模型答案是否正确，也没有完整核实填写是否成功。因此模型即使答错，仍可能触发提交。具体设置以脚本“设置”页和当前配置为准。

并非所有页面都有自动最终交卷逻辑。原版考试下一题、“下一步”等行为被保留，本修改不增加新的最终交卷动作。智慧树自动切换开关被忽略等已有问题也被保留。

图片地址按原来的题目提取方式作为文字传递，未新增视觉输入，不能保证图片题可答。联网资料及模型答案不保证正确。

API Key 没有预填，未读取电脑环境中的任何服务密钥。GM 存储不加密，不要公开完整配置。搜索时题干会发送到搜索服务；题干、选项和检索片段会发送给模型服务。费用、额度和答案质量由所选服务决定。
