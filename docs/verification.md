## 本地复现

安装 Node.js 22 或更新版本后，在仓库目录运行：

```sh
npm run check
npm test
```

离线测试只使用 Node.js 内置模块，不需要安装依赖，也不会调用外部模型服务。原始脚本保存在 `upstream/`，供哈希和源码对照使用。
