# 新手教程

[返回首页](../README.md) · [参数与接口](configuration.md)

这是安装在浏览器扩展里的 JavaScript 用户脚本，不是 Windows 安装程序。需要桌面浏览器、脚本管理器，以及你自己的模型服务配置。

## 1. 安装脚本管理器

1. 用 Chrome、Edge 或 Firefox 打开 [Tampermonkey 官网](https://www.tampermonkey.net/)。
2. 选择当前浏览器对应的扩展商店入口，安装 Tampermonkey。
3. 按扩展提示开启“允许用户脚本”等执行权限。不同浏览器和版本的开关位置可能不同，以 [官方说明](https://www.tampermonkey.net/faq.php#Q209) 为准。

完成标志：浏览器扩展列表里能看到 Tampermonkey，且处于启用状态。

## 2. 安装 CoursePilot AI

点击 **[安装当前脚本](https://raw.githubusercontent.com/Waffing/CoursePilot-AI/main/scripts/coursepilot-ai.user.js)**。

正常会弹出脚本管理器的安装页。核对名称末尾为“【大模型版】”、版本为 `0.2.8.2`，然后点击“安装”。

如果只显示代码或发生下载：

1. 到 [版本下载页](https://github.com/Waffing/CoursePilot-AI/releases/latest)，下载附件 `coursepilot-ai.user.js`。
2. 打开 Tampermonkey“管理面板 → 实用工具 → 导入”，选择下载的文件。
3. 在导入确认页核对脚本名称并安装。

在管理面板停用原版及其他同类脚本，保持只启用这一份。安装页会显示广泛的连接权限，这是为了允许自定义模型地址；实际连接请求应与你配置的服务一致。

完成标志：Tampermonkey 管理面板能看到启用的“【大模型版】”脚本。

## 3. 先检查自动提交

打开已经登录的学习通或智慧树课程页面，找到脚本浮窗。没有出现时先刷新，再检查 Tampermonkey 的页面访问与执行权限。

进入脚本“设置”，关闭对应平台的自动提交选项，核对其余开关。**首次配置阶段先关闭自动提交。**

原版章节作业可能默认开启自动提交，85 的阈值衡量的是“获取到答案的比例”，不是正确率。模型也可能答错，拿到答案不等于已经正确填好。部分页面没有最终交卷动作，本版没有新增这类动作。

## 4. 连接自己的模型

打开“答题 → 模型设置 → 连接”。

![连接设置，使用演示配置](assets/connection.png)

| 项目 | 怎么填 |
| --- | --- |
| 服务商 | 选择自己已经使用的服务商；中转服务可选“自定义”。 |
| 接口协议 | 按服务商文档选择。常见中转用 OpenAI Chat，Claude/Gemini 原生地址选择对应协议。 |
| 接口地址 | 填服务商给出的 API 地址，不是官网首页、聊天网页或控制台网址。 |
| API Key | 填模型服务密钥，不是登录密码，也不是原题库卡密。不要把 Key 发到 Issue 或截图里。 |
| 模型 | 等待列表加载并选择，或手动输入该接口实际支持的模型 ID 后按 Enter。 |

例如，你已有 DeepSeek API 配置时，可选择 DeepSeek 预设：默认地址是 `https://api.deepseek.com/v1`，协议是 OpenAI Chat。模型 ID 以自己的账户返回的列表为准。

“自动获取模型”默认开启。停止修改地址或 Key 约 0.8 秒后获取列表；也可点击“获取模型”。多个模型时需要自己选择，脚本不会自动替你挑选；只有一个模型时才自动选中。

点击“测试连接”。出现“连接通过，答案格式有效”表示本次示例题请求能返回脚本可识别的答案。此测试可能消耗额度，不会操作课程作业。

配置会自动保存。测试通过后刷新课程页面，再观察题目、返回答案与实际填写情况。**只有已运行的测试能说明当前接口状态，教程截图只是演示。**

## 5. 需要时再开启联网搜索

打开“联网搜索”页签，打开开关。两种方式任选其一：

### 服务商原生搜索

选择“服务商原生搜索”，继续使用当前模型 Key，不填 Tavily Key。

本版已接入 OpenAI Responses、Claude、Gemini 及百炼 Chat 的原生搜索。所选模型和中转接口仍必须支持搜索工具，不能仅凭服务商名称判断。

如果看到“当前协议未接入原生搜索”，可改用 Tavily。普通 Chat 接口没有通用搜索开关，在提示词里写“请联网”也不等于调用搜索工具。

### Tavily 先检索再作答

![搜索设置，使用演示 Key](assets/web-search.png)

1. 搜索方式选择“Tavily 先检索再作答”。
2. 搜索接口保留 `https://api.tavily.com`，或填写自己实际使用的 Tavily 兼容地址。
3. 在“搜索 API Key”填写自己的 Tavily Key，不能使用模型 Key 代替。
4. 设置检索条数和搜索深度，再点击“测试连接”。

脚本先检索，再把资料片段交给模型。搜索失败或没有可用资料时停止本题，不会悄悄切回无搜索模式。搜索服务也可能计费。

返回的来源在答案下方展开查看。“已联网检索”代表有检索记录；“服务商未返回搜索记录”表示无法确认执行了检索。不要把后者当作已完成联网查证。

## 6. 调整答题偏好

![答题参数示例](assets/preferences.png)

日常可先保持默认值。需要调整时：

| 选项 | 新手用法 |
| --- | --- |
| 超时 | 默认 120 秒，响应慢的服务可适当调大，最大 300 秒。 |
| 输出上限 | 0 表示不指定服务默认上限；设得过小可能导致答案不完整。 |
| 自定义温度 | 默认关闭。服务报参数不支持时也应关闭，由服务决定。 |
| 答题偏好 | 例如“简答题使用中文，保持简洁；优先核对课程定义”。不能保证模型一定遵守或答对。 |

“恢复答题参数”恢复此页的默认值。切换服务商时，会恢复各自保存的模型连接和答题参数；联网搜索配置是共享的，切换后也应检查。

## 常见问题

| 现象 | 检查顺序 |
| --- | --- |
| 没有浮窗 | 刷新课程页，检查脚本启用、网站访问权限和用户脚本执行权限。 |
| 401 / 鉴权失败 | Key 是否属于当前接口，是否完整、有效；不要公开 Key 排错。 |
| 403 | 检查账户、地域和模型权限，以及服务商的访问要求。 |
| 404 | 接口协议、路径和模型 ID 是否与服务商文档一致。 |
| 429 | 检查服务商限流、余额或配额。 |
| 获取模型失败 | 服务可能不提供标准模型列表；按文档手动输入模型 ID，再测试连接。 |
| 请求失败 | 检查网络与脚本管理器连接权限；先看是否允许该服务域名。 |
| 答案不是有效 JSON | 检查模型是否支持约定输出，输出上限是否太低，是否因服务端截断。 |
| 搜索工具报错 | 核对模型与接口是否支持该工具，或选择 Tavily 并填写独立 Key。 |
| 连接通过但课程未填写 | 连接测试只验证示例请求。查看日志、当前页面与题型；平台改版仍可能不兼容。 |

## 更新与卸载

更新：再次打开首页的安装链接，或导入新版 `.user.js`。在管理器核对是更新已有脚本，避免并存两份。此修改版未配置自动更新地址，应手动更新。

卸载：在 Tampermonkey 管理面板停用或删除脚本。删除时留意管理器对脚本存储的处理，Key 和个人设置可能随之清除。

反馈问题时，请提供浏览器、脚本版本、平台页面类型及已隐藏个人信息的错误截图。不要上传完整课程 URL、Cookie、Key 或含个人资料的配置。
